  • Kendi anahtarın — ücretsiz Gemini anahtarı yeter.
  • Asistan hep yanında — ekrandaki topla konuş.
  • Gizli — sohbetler cihazından çıkmaz.

API anahtarını ekle

Anahtar, yapay zekânın senin adına çalışmasını sağlar. Google AI Studio'da ücretsiz:

  1. aistudio.google.com/apikey adresini aç.
  2. “Create API key” düğmesine dokun, Google hesabınla giriş yap.
  3. Oluşan AIza… ile başlayan anahtarı kopyala.
